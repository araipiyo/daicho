# Contributing

Thank you for your interest in Daicho.

Daicho is currently in an early design and implementation phase. We welcome issues, feedback, and pull requests, but all code contributions must pass the Contributor License Agreement check before they can be merged.

## Contributor License Agreement

By submitting a pull request or other contribution to this repository, you agree to the terms of the Contributor License Agreement in `CLA.md`.

Substantial code contributions may be rejected or closed if the CLA check is not completed.
